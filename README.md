# yigrass.github.io

Meet me here.

这是一个以 Windows 95/98 桌面为视觉参考的个人空间原型。网站使用原生 HTML、CSS 和 JavaScript，可由 GitHub Pages 直接托管，无需安装依赖或执行构建。

## 本地查看

使用浏览器打开 `index.html`。初始桌面只有背景和任务栏，没有预先打开的内容窗口。点击左下角“开始”，再打开个人信息或个人作品。

窗口支持最小化、最大化、还原和关闭；任务栏中的窗口按钮用于切换或还原。宽屏下可以拖动窗口标题栏。窄屏下窗口占据主要内容区，菜单浮在桌面上，选择内容后收起。

开始菜单的“桌面设置”提供菜单透明度、自定义光标和漂浮星星开关。菜单默认不透明，透明度仅作用于菜单主体底色。设置在浏览器允许时保存在本机；部分浏览器直接打开本地文件时可能不保存设置，但不影响基本浏览。系统偏好减少动态效果时不播放星星动画。

## 编辑网站

编辑 `assets/site-config.js`，可更改开始按钮文字、菜单名称、个人信息、作品条目、背景地址和默认设置。文件中的注释提供字段说明。菜单名称与模块身份分开，所以改名不会改变对应模块。

当前资料仅使用仓库已存在的信息：昵称为 `yigrass`，签名为 `Meet me here.`。头像、介绍和作品等待添加；未虚构小说、链接或游戏。头像为空时显示昵称首字母，作品为空时在作品窗口展示空列表状态。

默认背景是 `assets/wallpaper.svg` 中的经典青绿色占位图。可以把自己的图片放入 `assets/`，再修改 `wallpaper` 和 `wallpaperPosition`。背景等比例铺满页面，不同屏幕可能裁剪图片。

作品条目支持标题、小说或游戏类型、简介、可选封面和链接。第一版提供作品入口，小说阅读器与游戏内容由后续作品接入提供。音乐播放和完整 JRPG 主题不属于本版。
