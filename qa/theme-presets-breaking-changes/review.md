本轮按用户要求接入五套预设主题，移除旧项目地址兼容，并将默认破坏性迭代政策写入 README。主题会即时作用于所有窗口、开始菜单、任务栏、应用按钮和滚动区域，在本机存储可用时保存选择。默认仍为 `95's（异化）`；没有更改壁纸、桌面填充、背景边缘 dithering、图标文件或 20px 滚动条尺寸。

## 实现

`assets/themes.js` 是预设颜色的权威来源。五套主题依次为 `95's`、`95's（异化）`、`深渊`、`苔痕`、`幽涧`。经典蓝色 `#000080` 从本地历史版本 `28faed9` 的 CSS 核对；后三套分别采用前轮 A、B、C 候选的基色、内容背景、文字和标题栏颜色。CSS 以语义颜色变量覆盖现有组件，夜间 UI 滚动轨道使用配套深色点阵，单色窗口按钮通过显示滤镜提高对比；美术资产不重绘。

系统设置增加“主题”模块，包含使用同一箭头图片旋转的“预设”和“自定义”折叠入口。打开设置时按照当前主题所属的预设类别展开；切换展开项会收起另一项。预设采用同组原生 radio，保留键盘选项行为，每项展示“控件背景”“内容背景”“标题栏”的 RGB 值和色块。“自定义”仅有 `aria-disabled` 标记的灰色“功能开发中”，没有可写控件，不改变当前主题。完整编辑能力记录为 Custom Themes 待开发任务。

主题选择与透明度、光标和星星设置分别保存，切换不重新创建窗口或增加历史记录。无效设置回退到配置默认主题；读取或保存本机存储失败不阻止当前页面切换。这是输入有效性和可用性处理，没有旧主题格式迁移分支。

已删除 `novels/story-a/index.html`、`games/game-b/index.html` 及其空目录，从配置和路由目录移除旧别名；当前仅生成九个应用、磁盘、文件入口。README 的“开发约定”为默认不保留兼容层的权威记录，后续地址变更应一并清理旧入口。生成入口仍位于根目录，以保持当前公开地址。
