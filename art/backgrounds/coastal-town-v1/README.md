用户希望网站像一台被人捡到、可以探索原主人遗留物的电脑；气氛温和，不走恐怖方向。背景可以从未来收录的小说城镇取材。第一版先采用通用的夏末傍晚海边小镇，作为原主人长期使用的一张私人壁纸。未来随阅读章节切换城镇背景的想法已记录为 Chapter Backgrounds 待办，本轮不实施。

本候选使用内置 OpenAI image_gen 工具生成，原始完整提示词见 `prompt.txt`。画面包含下坡小路、低矮屋顶、平静水面、灰蓝海天和一扇暖黄色窗户。视觉检查确认无人、无文字、无网页界面、没有恐怖元素；建筑与植物呈现偏南欧海岸的感觉，可由用户判断是否适合其小说世界。

`draft.png` 是工具原始输出的完整副本，没有再采样或调色处理。请求尺寸为 1536×864，实际输出为 1672×941，接近 16:9。PNG 为每通道 8-bit RGB（color type 2），不是 8-bit 索引色 PNG；也未验证严格统一的像素网格。这一轮用于确认构图与气氛，不能作为已完成像素规格整理或多屏适配的证据。

图片已通过 System.Drawing 解码并读取尺寸，复制前后 SHA-256 一致，记录见 `manifest.json`。原始生成文件保留。候选暂存于本目录，网页仍使用原背景；未修改网站资源引用、未启动开发者模式或章节背景切换、未执行 Git 写入或远端操作。
