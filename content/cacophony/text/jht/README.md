# 露力丽的歌

城都正在发生一些变化。

古老的势力仍在维持旧日的秩序，新的力量却已经悄悄出现。远方的传闻、彼此试探的目光，以及那些暂时还无人能够解释的变化，正沿着山脉、湖泊与城镇之间缓慢蔓延。

露力丽原本只想处理好自己留下来的事情。

利欧路则只是突然出现在若叶镇，一个没有来历、没有去处，甚至不知道自己为什么会来到这里的异乡人。

他们本来不该有什么关系。

可从相遇的那一天开始，两条原本毫不相干的道路，还是一点点交汇到了一起。

于是，他们开始旅行。

从若叶镇吹起的风，越过古塔、遗迹、森林与旧城，也将他们带向一个正在改变的城都。

有些人试图抓住过去。

有些人正在寻找未来。

而他们首先要弄明白的，或许只是——

接下来，要和谁一起走下去。
